# Computer Graphics Project
Computer Graphics project for the 2023/2024 academic year.

# Instructions
1. `git clone https://github.com/Koc13/MatfRG-Project.git`
2. CLion → Open → path/to/my/project_base
3. The main file is located in `src/main.cpp`
4. `ALT + SHIFT + F10` → `project_base` → Run

# Controls
1. **WASD**: Movement
2. **Mouse**: Camera control

# Implemented Features
1. Face culling
2. Blending
3. Advanced lighting
4. Skybox cubemaps
